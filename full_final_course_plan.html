Key Rules
  • Local-first: All 9 phases run on your local Windows machine. Google Colab is used exactly once — Phase 7 — for GPU access during fine-tuning. Groq handles all cloud LLM inference for free.
  • Database-connected from Phase 2: Every agent and RAG pipeline connects to real databases — PostgreSQL, SQLite, and vector stores. Students learn LLM-to-database strategy across dev, test, and prod environments.
  • Lab types per module: Guided lab (60% scaffolded) → Solo exercise (write from scratch, pytest validates) → LangSmith eval run (automated score on frozen dataset = the grade) → Challenge (open-ended).
  • Submission format: GitHub notebook link + LangSmith trace share link. Instructors replay any student's exact run. Peer reviews happen in GitHub PRs.
  • Self-paced: 20 weeks is the suggested part-time pace (~8–10 hrs/week). No deadlines — finish faster or slower.
